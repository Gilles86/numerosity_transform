# numerosity_transform

Learning a mapping from numerosity (number of dots) to monetary value (linear, concave or convex), measured with
estimation and a BDM auction. Behavioural port of `abstract_values` with numerosity stimuli from `neural_priors`.

The PsychoPy/exptools2 experiment and the participant instruction booklets are in [`experiment/`](experiment/README.md):

```bash
python experiment/start.py   # any python 3; installs uv (and the environment) on first run
```
